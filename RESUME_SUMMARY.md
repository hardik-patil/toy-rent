# ToyRental Platform — Resume Summary

Designed and built a Kubernetes-deployed microservices platform for a toy rental marketplace — three Spring Boot services (API gateway, catalogue, booking/payments) communicating over a mix of synchronous REST and an event-driven Kafka backbone, each with strict database-per-service ownership across PostgreSQL and Couchbase. Load-tested the platform with Apache JMeter under mixed-workload traffic and independently diagnosed and fixed three production-grade performance bottlenecks — cutting login p95 latency from 7.3s to 3.3s and eliminating a BCrypt/connection-pool-driven error cascade — backed by a full observability stack (Prometheus, Grafana, Zipkin distributed tracing, New Relic APM) for root-cause analysis. **Tech stack:** Java 17, Spring Boot 3.2 / Spring Cloud Gateway, Apache Kafka, PostgreSQL 15, Couchbase, Redis, MinIO, Docker, Kubernetes, Helm, Apache JMeter, Prometheus/Grafana, Zipkin/OpenTelemetry, New Relic, AWS Elastic Beanstalk, React/Vite.
